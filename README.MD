
# Resumo de Git e Github

Git é um sistema de controle de versão distribuído que permite rastrear mudanças no código-fonte de um projeto. Ele possibilita que desenvolvedores trabalhem simultaneamente, façam alterações sem sobrescrever o trabalho uns dos outros e revertam mudanças quando necessário. Alguns dos principais comandos do Git incluem:

git init – Inicializa um repositório Git.
git clone [URL] – Faz o download de um repositório remoto.
git add [arquivo] – Adiciona arquivos ao controle de versão.
git commit -m "[mensagem]" – Registra mudanças no repositório.
git push – Envia as alterações para um repositório remoto.
git pull – Atualiza o repositório local com mudanças remotas.
git branch – Gerencia ramificações do código.
git merge – Junta diferentes versões do código.
GitHub é uma plataforma online que hospeda repositórios Git, facilitando o compartilhamento, colaboração e gerenciamento de projetos. Ele oferece recursos como controle de permissões, pull requests, issues (para rastreamento de problemas) e integração com outras ferramentas.

Em resumo, Git é a ferramenta usada para controle de versão, enquanto GitHub é um serviço baseado em nuvem para hospedar e gerenciar repositórios Git.
